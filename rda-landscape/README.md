# RDA Landscape

Marketing site + AI instant-quote tool for RDA Landscape (Ryland Adams
Landscaping) — Landscaping, Lawn Maintenance & Snow Removal in Louisville,
KY and surrounding counties.

Stack: Next.js (App Router) + TypeScript + Tailwind CSS v4 + shadcn/ui,
deployed to Netlify.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Project status

Built in phases — see the project conversation history for the full plan
(design system, sections, AI photo-quote tool, deploy, SEO, security
hardening). Secrets (Anthropic API key, Web3Forms key, etc.) live only in
Netlify Environment Variables — never in this repo.
